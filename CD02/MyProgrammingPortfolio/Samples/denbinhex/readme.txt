Base conversion project
08/02/00

******************************************************
Author : Mr T (grredo@hotmail.com)

This project converts a value of hex (base 16), denary (base 10), binary (base 2) or ascii into each of the others.  Due to ascii and a byte having a max value of 255 I didn't bother exceeding this for all conversions, but you can easily modify the code to do it.

I produced this when I started doing some machine code and assembly language programming, when knowing hex was useful.  Like the about box says I'lI started work on a binary calculator to deal with 2s complement, binary fractions, binary exponential etc but unfortunately that has been put on hold due to a general excess of work.

If you use this code for anything then give credit where it is due.  It is the way that you say thank-you for the effort that was put in by the contributor.

Ps: When writing code of your own document properly as you go along, roughly a third of the time I spent on this was documenting it months after I programmed it.  Document while you are letting the code flow.  It is worth it, although it may not seem so at the time.
